# Анализ загруженности парковки торгового центра

Веб-приложение для автоматического обнаружения и подсчета автомобилей/мотоциклов на изображениях с использованием предобученной модели **YOLOv8**.

* Загрузка изображения через веб-интерфейс
* Детекция автомобилей/мотоциклов
* Отображение результата с рамками на заранее заданных местах
* Подсчет количества обнаруженных объектов
* Сохранение истории обработок в базе данных SQLAlchemy
* Генерация файла Excel с историей обработок

## Установка

Клонировать репозиторий

```bash
git clone <ссылка_на_репозиторий>
```

Перейти в папку проекта

```bash
cd parkinCheck
```

Создать виртуальное окружение

```bash
python -m venv venv
```

Активировать виртуальное окружение

```bash
venv\Scripts\activate
```

Установить зависимости

```bash
pip install -r requirements.txt
```

---

## Запуск

```bash
python app.py
```

Либо можно использовать приложенный файл запуска **run.bat**

После запуска приложение будет доступно по адресу

```
http://127.0.0.1:5000
```
